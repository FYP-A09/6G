Unified environment: answers to the 12 Oct review

No public dataset joins traffic, topology, slices, actions and SLA outcomes, so we built one: real Milan traffic on the real grid, latency calibrated on the 6G RAN telemetry dataset, load-coupled interference. Trained on 5 real days, tested on the next 2; 3 seeds each.

Why the split mattered

Same encoder, same classifier. The file is ordered in same-label blocks, so a sequential split put 99.9% of one class in the test set.

Benign recall is the weak point: the SSL embedding finds 41% of benign flows (raw features: 40%), while it finds 99.9% of malicious ones. Training and validation losses differ by two orders of magnitude and we have not explained the gap, so the downstream F1 is our evidence, not the loss.

Hyperparameter search (validation reward)

All eight settings land within 0.001, so the search tells us nothing about tuning.

The reward is nearly trivial: B5G has no latency, jitter or packet-loss values (0 of 4,350 sampled slices), so the only action-dependent term pays for giving a slice more share. Beating the heuristic shows the pipeline works, not that the policy is a strong slicer. Single seed, 50 test samples.

Topology and simulator checks

Nearest-gNB association: moderate negative correlation between distance and recorded SINR, and every UE inside its assigned cell's range. Simu5G: one gNB and one UE carrying VoIP downlink for 5 simulated seconds. The project's own 19-gNodeB scenario is not wired in yet.
